### What changed since the baseline (final, frozen evaluation)

"This run" is the **mean of runs 1 and 2** (N = 2). A third run was recorded but cut short
by Groq's free-tier limit of 200,000 tokens per day for `gpt-oss-120b`: 33 of its 50
questions got no LLM answer. It is kept in the raw JSON and left out of every number here.

**Measurement fixes — not system improvements.** The middle column re-scores the
baseline's own answers: the 12-hour-time fix in the key-fact check (`fix(eval)`, 95c1fea)
and the key facts of a05, a07, a12 (see the dataset changelog). Only the first changes a
baseline score (a34): +2.8 pp answer accuracy. Nothing the system outputs changed.

**System fix.** `fix(rag_core)` (dc077b1) accepts `【1】`-style citation markers that
`gpt-oss-120b` often writes; before, those correct answers were discarded as uncited.
That explains the drop in false refusals (25.0% → 2.8%) and most of the accuracy gain.

**n13 "Can I pay with Bitcoin?" — disputed label, kept as NO_ANSWER.** `payment.txt`
says the settlement currency is only the Kyrgyz som. If Bitcoin counts as a currency, that
sentence excludes it and the question is answerable ("no"); if it counts as a payment
method, the list of methods is open and the question is unanswerable. The rule does not
settle it, so the label stays. Consequence: an answer like "No, Bitcoin is not accepted
[1]" is counted as a hallucination although it is defensible.

## How to read this

- Answer accuracy is a strict lexical check: every key fact (mostly numbers) must appear in the answer. It under-counts correct paraphrases and over-counts answers that mention the right number in a wrong statement; use `--llm-judge` for a second opinion.
- Citation validity uses rag_core's own lexical check (a cited sentence must share a number or content-word stem with the passage). It cannot verify answers in a different language from the source (Kyrgyz/English answers over Russian documents).
- In retrieval mode refusals come from the `min_score` threshold alone.
- 50 questions over 7 short documents: one question is 2–3 percentage points, so differences of a few points between runs are noise.
