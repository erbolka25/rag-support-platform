## How to read this

- Answer accuracy is a strict lexical check: every key fact (mostly numbers) must appear in the answer. It under-counts correct paraphrases and over-counts answers that mention the right number in a wrong statement; use `--llm-judge` for a second opinion.
- Citation validity uses rag_core's own lexical check (a cited sentence must share a number or content-word stem with the passage). It cannot verify answers in a different language from the source (Kyrgyz/English answers over Russian documents).
- In retrieval mode refusals come from the `min_score` threshold alone.
- 50 questions over 7 short documents: one question is 2–3 percentage points, so differences of a few points between runs are noise.
